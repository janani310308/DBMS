# Product and Category Management System

## Overview
The Product and Category Management System is a database application developed as part of the Week 2 DBMS assignment. It manages product and category information using a relational database. The system demonstrates table creation, relationships, and SQL operations.

## Objectives
- Design Product and Category tables.
- Define Primary Key and Foreign Key relationships.
- Store product information such as name, category, price, and stock.
- Perform INSERT, UPDATE, and DELETE operations.
- Generate category-wise product reports.

## Technologies Used
- MySQL
- SQL
- Git
- GitHub

## Files
- `schema.sql` – Table creation scripts.
- `insert.sql` – Sample data insertion.
- `update.sql` – Update operations.
- `delete.sql` – Delete operations.
- `reports.sql` – SQL queries for reports.
- `ER_Diagram.png` – Entity Relationship Diagram.
